1.- clonar proyecto del repo Github

git clone [url]

2.- situarnos dentro de la carpeta del proyecto clonado

3.- crear nuestra rama y situarnos dentro

git checkout -b nombrerama

4.- comprobar ramas (opcional)

git branch

5.- añadir nuestras modificaciones al proyecto clonado

6.- poner en stage las modificaciones realizadas

git add .

7.- realizar el commit 

git commit -m "mensaje"

8.- Subir proyecto al repo si queremos ver la rama creada (opcional)

git push -u origin main

9.- cambiar a rama main 

git checkout main

10.- fusionar las ramas (siempre desde la rama pricipal)

git merge nombrerama

11.- realizar push al repositorio Github

git push -u origin main

12.- En Github deberíamos ver nuestros cambios

13.- Si necesitamos realizar más cambios lo primero es volvernos a traer el repositorio 

git pull 

14.- creamos una nueva rama y seguimos de nuevo los pasos anteriores
